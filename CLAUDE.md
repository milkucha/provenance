# Working in this repo

New session, any agent: read `README.md`'s intro plus §0–§2 first — that's the compulsory
orientation minimum, before exploring further. See the README's own "Index" section for what's
compulsory vs. task-specific.

Two more files apply to every session and every skill here, not just README-reading ones:

- `.claude/PRINCIPLES.md` — house philosophy. Currently: nothing gets decided silently (open
  questions go to the user or get logged, never guessed).
- `.claude/VOICE.md` — project prose (README, TODO, LAB_REPORT, commit messages, in-repo notes)
  gets written in the author's own voice, not default assistant prose. Has the rule plus a growing,
  dated list of the author's actual verbal patterns to imitate.

**Before ending a session** that covered landmark ground — a design decision, a changed mind, a real
disagreement and its resolution, a surprising result, a new open question — append a short entry to
`CHRONICLE.md` at the repo root. Not every session needs one; see that file's own header for what
counts and how much detail belongs there (short — a spine of landmarks, not a transcript).
