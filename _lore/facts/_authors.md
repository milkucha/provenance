# Authors — Real-World Recordkeeping

This file tracks which *real* user added each fact, and when — administrative metadata about the
record's own history, not lore. Facts have no in-fiction attribution at all (see `_index.md` —
"nobody told them"), so unlike `_lore/tale/_authors.md` there is no in-world counterpart this file
needs to stay distinct from; `responsible` is simply the only provenance a fact ever has, and it's
real-world only. Mirrors the same isolation rule as the tale-folder version: never read by any skill
that plays a character, and irrelevant to `scripts/sample_lore_knowledge.py` since facts are never in
its pool at all.
