# Authors — Real-World Recordkeeping

This file tracks which *real* user (or process) added each fact, and when — administrative metadata
about the record's own history, not lore. Never read by any skill that plays a character, and
irrelevant to `scripts/lore/sample_lore_knowledge.py`, since facts are never in its pool at all (see
`_index.md`). Facts have no in-world attribution at all, so unlike a tale's `told_by` there's no
in-fiction counterpart this file needs to stay distinct from — `Responsible` is simply the only
provenance a fact ever has.
